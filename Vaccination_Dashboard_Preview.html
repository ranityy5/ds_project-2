Data notes

What was done to the data and what it cannot tell you.

Cleaning

    Questions the data cannot answer

    • Gender: only HPV coverage is split by sex.
    • Education, urban vs rural, population density: not in the dataset (target-cohort size is used as a rough size proxy).
    • Seasonality: data are annual, not monthly.
    • Door-to-door vs clinic strategy: delivery method is not recorded.
    • Influenza outbreaks: no influenza case counts, only vaccine coverage and programmes.

    Findings are associations across countries, not proof of cause. This page set is a browser preview; the Power BI report is built from the same cleaned tables using the guide in the project folder.
